Say a friend trades you while Auto Fishing is running, or you want to check your bank yourself for a minute. Until now you had to turn the script off and set it up again afterwards. 2.6.53 adds a pause button to the client header: one click pauses every running script and gives you the mouse and keyboard, and a second click lets them carry on where they stopped. You can also add, update and remove plugin JARs from a new Local Plugins window without restarting Microbot. On top of that, Quest Helper stops walking once you turn Semi-Auto off, bank trips pick a bank you can walk to instead of teleporting home, and relogs no longer fail on a world change. On the Hub there is a new Sulliuscep woodcutting plugin, bigger updates to Auto Gauntlet, Barbarian Fisher, Thieving, Arceuus Library, Tithe Farm, Fletcher and Drift Net, and 13 more fixes, among them Tempoross, Barrows, Wintertodt and Giants' Foundry.

Pause every script at once

There is a new pause button in the client header, right next to the Enable/Disable Input button. Click it and every running script pauses. Your plugins stay on, and nothing is reset: a script that was halfway through a bank trip still knows where it was going. Manual input is turned on and the game window gets focus, so you can click and type straight away.

While scripts are paused, the button turns into an amber play button. Click it to resume. Input goes back to how it was before you paused, unless you changed it yourself in the meantime.

Before

You're running Auto Mining and a clan mate asks for a trade. You turn the plugin off, trade, turn it back on, and the script starts its routine again from the beginning.

2.6.53

You click pause, accept the trade, and click the amber play button. Auto Mining checks where you are and keeps mining. The client log says "All scripts resumed".

A few things to know:

  • The game keeps going. Pause stops Microbot from sending new actions. If your character was already walking or fighting, the game finishes that action. Check where you are before you resume, for example if you paused in the middle of a fight.
  • No stray clicks or text. A click or a line of text a script was about to send when you paused is thrown away, so half a message from a script never ends up in your chat.
  • Breaks still happen. Pause doesn't change Break Handler. If a break was due while you were paused, it starts when you resume.
  • Each plugin tells you once. A script that wants to act while paused writes one line in your game chat, such as "Auto Fishing is waiting: scripts are paused", instead of filling it up.
  • It lasts until you resume. Logging out or hopping worlds doesn't undo it. Closing the client does.
Does every plugin pause?

Plugins built on Microbot's own script loop pause right away, which covers most of the Hub. A plugin that runs its own timers or threads may keep some of its logic going. Clicks and key presses it sends through Microbot are still blocked while you're paused.

Add plugin JARs while the client runs

If you test plugins that a friend built, or build your own, you used to drop the JAR in a folder and restart Microbot every time it changed. Open the Microbot plugin list and click Local Plugins at the top. The window that opens lists every plugin JAR in your plugin folder, with its version and whether it's running:

  • Add JAR copies a JAR into the plugin folder and loads it. Turn the plugin on in the plugin list afterwards.
  • Update JAR swaps the selected plugin for a newer JAR and keeps your settings.
  • Reload restarts the selected plugin from its JAR.
  • Remove turns the plugin off and deletes its JAR from the folder. Your settings are kept, so they're still there if you add it again.
  • Rescan folder picks up JARs you added, replaced or deleted in the folder yourself.
  • Watch folder for changes loads a JAR about two seconds after it stops changing, so you can copy in a fresh build and see it in the client right away.
  • Change folder... switches to another plugin folder. Every plugin in the current folder is turned off, including ones from the Plugin Hub, but their files stay where they are.

For example, a friend sends you MyPlugin.jar with a fix. You click Add JAR, pick the file and turn the plugin on. When they send version 2, you select it, click Update JAR, and your settings are still there. The folder is .runelite/microbot-plugins in your home folder unless you change it.

The Microbot Plugin Hub got a few changes along the way:

  • Installing, updating and removing a Hub plugin now runs in the background. The button shows that it's busy, and if something fails you get an error window instead of nothing happening.
  • When the Plugin Hub can't load its list, it shows a Retry button.
  • The "Microbot Plugins Not Loaded" notice at startup now also lists JARs that failed to load or need a newer client, not only in the log.
  • A plugin that hit an error while being turned off can be turned on again without restarting the client.

Quest Helper fixes

  • Semi-Auto off means off. Two players turned off Semi-Auto questing with the Quest Helper icon in the toolbar, and their character kept walking to the step that was active before, back and forth, even after the plugin was off. Turning Semi-Auto off, from the toolbar icon or the settings, now stops the walk at once. You also no longer get a "Quest helper stopped" message blaming your bank or coins after you turned it off yourself.
  • Cold War penguin trips. After the visit to the Lumbridge sheep farm, Quest Helper went straight back to the Ardougne Zoo penguin pen in human form. The walker clicked the enclosure door over and over, and the game answered "I can't go in there." each time. It now has Larry use Tuxedo-time on you first, and reminds you to bring a raw cod or wear the Ring of Charos (a), and to take off your cape and weapons. The steps where you talk to the Thing in Lumbridge also check that you're a penguin.

Banking and login fixes

  • A bank you can walk to. A player mining coal at the Barbarian Village mine with banking on saw Auto Mining cast Lumbridge Home Teleport when the inventory filled, bank at the top of Lumbridge castle, and then walk about 267 tiles back to the rocks. Edgeville bank was a short walk away. Scripts that bank and walk back, and the same for deposit boxes, now pick the closest bank on foot and only use teleports when no bank can be reached by walking. The log tells you why, for example "Banking at EDGEVILLE (closest bank on foot, so the walk back stays short)".
  • Relogs after a lost connection. When Break Handler tried to log a player back in after the connection dropped, the client tried to change worlds before it was on the login screen. Every attempt failed with an error, 18 times in 25 minutes for one player. The client now only changes worlds on the login screen.
  • A world to hop to, always. When no world matched a script's filters, for example a members world in a region that had none listed, picking a random world threw an error. House Thieving stopped with a message that meant nothing to the player. The client now falls back to world 360 for members or 383 for free-to-play.
  • Inventory Setups open again. Clicking a setup whose saved inventory or equipment list was shorter than the full slot count threw an error. The panel stopped halfway, so the rune pouch, equipment, spellbook and notes never showed, and you couldn't open or edit the setup. Short lists are now filled with empty slots and the setup opens normally.

Plugin updates

Dro Sulliuscep Run1.0.0

A new plugin that chops Sulliusceps on Fossil Island, at up to about 105k Woodcutting XP an hour. It travels with a digsite pendant and the Magic Mushtree to the Sticky Swamp, handles the vine route, and keeps the mushrooms and fossils you find. You choose between banking every run or filling the rubber cap mushroom and jumping on it, and you can drop fossils you already have. It can restore special attack and bank at the Ferox Enclave, or use your house through Castle Wars or the Crafting Guild. It eats, cures poison and handles monsters that attack you. Equip your forestry backpack once before you start, and start next to the tree.

Auto Gauntlet1.8.0

In the Hunllef fight it picks better between actions when several are due at once, times food and potions more reliably and moves more accurately. During prep, the Egniol potions setting now makes the number of potions you set (2 by default), the overlay's "Missing" row updates as soon as you change a setting, fishing stops at your paddlefish target, and the route after the first demi-bosses is shorter, so your full loadout is ready more often. Pressing the pause or continue hotkey also no longer freezes the client for up to 10 seconds.

Barbarian Fisher1.2.0

You can now fish at Mount Quidamortem, the lake by the Chambers of Xeric, as well as Otto's Grotto. There it fills your fish barrel while you fish and empties it with your leaping fish at the Chambers of Xeric bank chest. You can also have it use the dragon harpoon special attack for the +3 Fishing boost whenever your spec bar is full, and pick the order it drops fish in.

Thieving2.2.0

Start the plugin at the Grand Exchange with NPC to Thieve set to Man, and it used to hop worlds forever looking for men who were never there. It now walks to the nearest place the NPC you picked spawns, outside the Wilderness, and only hops once it's there and the NPC is missing. If it can't find anywhere to go, it stops with a message. Turn off Walk to NPC location to get the old behaviour.

Arceuus Library1.0.4

Started in Varlamore, the plugin never reached the library: it sent a new walk every tick and could only use local routes. It now travels there with ships, charters and teleports, tries Arceuus library or Kourend castle teleport tabs from your inventory if walking fails, and stops with a clear message after three failed tries. New options: drink stamina or energy potions at the run energy you set and fetch more from the bank, Reward skill set to Auto to pick whichever of Magic or Runecraft gives more XP, and Read reward book.

Tithe Farm1.1.17

The new Use 16 plants option leaves the short extra column of the lane empty and plants 16 patches instead of 19 or 20, so every plant gets watered in time. It applies from the next round.

Fletcher1.7.1

When you string bows and the bank has a bow string spool with string on it, the plugin takes the spool and up to 27 unstrung bows instead of 14 strings and 14 bows, so each trip strings 27 bows. An empty spool falls back to normal bow strings.

Drift Net1.1.2

An update to the existing drift net plugin. It sets your nets, watches how full they are, loots full nets and resets empty ones right away, and chases shoals by distance, angle and line of sight. It restocks nets from Annette, and the overlay shows runtime, Fishing and Hunter XP per hour, your next break and the current status.

More Hub fixes in this release:

  • Tempoross 2.24.9: in solo games, the bot ran back and forth between fires on the other boat and the fishing spot until the game was lost. It now only douses fires within 5 tiles of you or near your own mast, crates and pump.
  • AI-Wintertodt 2.2.6: with 500 or more points and no food left at low warmth, the character waited at the door for the round to end and could die in the arena. It now leaves to restock, and the log says how many points that costs and suggests raising Healing Items Per Trip.
  • Barrows 2.5.26: one player kept about 5,400 Blood runes in a rune pouch, and the script did nothing but log "We have less than 180 Blood rune" several times a second. Runes in the rune pouch now count. Without a Ring of dueling to leave for the bank, it now stops and tells you.
  • Bank's Shopper 1.4.5: when the item you buy is sold out, it hops worlds instead of opening and closing the empty shop. Running out of coins no longer freezes the client behind a pop-up, the plugin turns itself off properly, and turning it off by hand no longer logs you out.
  • Giants' Foundry 1.0.9: the bot stayed at the polishing wheel or trip hammer for one action after the heat had left the range, which cost 5 quality each time and up to 20 over a trip. It now leaves before that action.
  • BlastoiseFurnace 1.2.5: with the open coal bag in your inventory, the script stopped with "No coal bag found in inventory and bank." It now recognises both the open and the closed bag.
  • Nmz 2.4.6: when the reward chest asked for your bank PIN and your Microbot profile had none saved, the script crashed on every tick and bought no potions. It now stops and tells you to add your PIN to the profile.
  • Auto Fishing 1.0.12: after banking at the Isle of Souls chest, a player fishing trout at Barbarian Village was walked to the Observatory instead. The script now goes back to the spot you were fishing.
  • Agility 1.3.4: on the Al Kharid rooftops the script said it was looting a mark of grace and then ran on to the next obstacle. It now picks up marks it spots while you're moving.
  • Jewelry Crafter 1.0.4 and Crafting 1.0.6: started at a bank with an empty inventory, Jewelry Crafter did nothing and logged an error every loop when no antiban activity was set. Jewelry and Glassblowing now run normally in that case.
  • MotherlodeMine 1.9.12: no more reset of the whole script in the middle of a trip when it tried to walk before a mining spot was picked.
  • Mahogany Homes 0.0.20: no more error during a ladder or stairs climb, while your position is briefly unknown.
  • MTA 1.1.11: after New-maze in the Telekinetic room, the script now waits until you've left the old maze, and it no longer errors while your position is briefly unknown.

Other changes

  • Spell casting is more reliable. High Alchemy in AIO Fighter could fail with an error when the spell's options changed in the middle of a cast. Each cast now reads them once.
  • When the "How many would you like to make?" menu closes just as a script reads it, the script now treats it as closed and tries again, instead of stopping its loop with "Unexpected error in scheduled loop".
  • A script that looks for a button in an interface that has just closed now gets "not found" quietly, without an error in your log.

For script developers

  • ScriptPauseController.isPaused() tells you whether the header pause is on. Custom threads can call ScriptPauseController.awaitResume() at safe points outside locks, and activeTimeNanos() gives a clock that leaves out paused time. Never wait on the client thread or the Swing thread. See docs/manual-pause.md.
  • The Agent Server state reports manuallyPaused next to scriptsPaused, and input endpoints return "Scripts are paused" as the reason while paused.
  • The new :client:pluginJar Gradle task builds a standalone JAR from one plugin package, for example -PpluginPackage=...yourplugin -PpluginClass=...yourplugin.YourPlugin. The JAR only loads into a client that doesn't already contain that package. See docs/live-plugins.md for the lifecycle rules a plugin needs to reload cleanly.
  • Rs2RouteRequest.withoutTeleports() asks the pathfinder for a walk-only route. The bank-and-return helpers in Rs2Bank and Rs2DepositBox use it first.
  • LoginManager only calls changeWorld on the login screen, and Login.getRandomWorld returns 360 or 383 when no world passes the filters.
  • Two merges of main into development, with no change for players.

How to update

Restart Microbot to get client 2.6.53. The pause button is in the header next to Enable/Disable Input, and Local Plugins is at the top of the Microbot plugin list. The new and updated plugins show up in the Microbot Hub panel inside the client.
