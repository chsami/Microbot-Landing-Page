Microbot 2.6.59

Up to date with RuneLite 1.13.7 and this week's game update

2.6.59 is a small release with one job: it moves Microbot to RuneLite 1.13.7, so the client matches the game after this week's update. There are no new Microbot features and no plugin changes in it. You get the new game content recognised by the client, RuneLite's support for hardcore main worlds, a few small RuneLite fixes, and a Spoof device ID option that keeps working on the new game revision.

Ready for this week's game update

Every game update changes the game's internals, and the client has to be rebuilt against them before it can be trusted again. 2.6.59 is that rebuild.

  • Matches the current game. The client is built on RuneLite 1.13.7, which targets the game revision that went live this week.
  • New content has names. Items, NPCs, objects, interfaces and quests added by the update are known to the client. For example, an item added this week shows up by name in item lists and in plugin settings instead of as an unknown ID.
  • Your plugins carry on. The Hub plugins were compiled against this client before it shipped, and none of them needed a change.

Hardcore main worlds

RuneLite 1.13.7 teaches three of its plugins about hardcore main worlds, and Microbot gets all three.

  • World Hopper: the world type filter has a Hardcore main choice, so the world list can show only those worlds.
  • Prices: while you are logged in to a hardcore main world, item prices in the client come from the hardcore main price list instead of the normal one. Anything that shows a value, such as the bank value or a loot tracker total, follows it.
  • Hiscores: looking up a player who has the hardcore main icon next to their name in chat opens the hardcore main hiscores, both from the right-click Lookup option and from chat commands such as !lvl.

Small fixes from RuneLite

  • Key Remapping: with WASD camera keys on, typing in the display name change box moved the camera instead of typing. The plugin now leaves your keys alone while that box is open.
  • Music: the option that mutes prayer sounds now also mutes Zeal.
  • Clue Scrolls: the Lumbridge cipher clue and two clue texts that mention a sword, now a shortsword, are updated, so the helper recognises them again.
  • Item values: the Obligator and Zorya's tome are valued by what they are made from.

Spoof device ID keeps working

If you turned on Spoof device ID, the client keeps the game's own identity file out of the way while spoofing is on. This week's game revision changed the code around that file, and without a fix the client would have stopped guarding it. 2.6.59 recognises the new form, and a test that checks it against every past game revision ran before the release. If you never turned the option on, nothing changes for you.

For script developers

  • RuneLite 1.13.7 adds net.runelite.api.gameval.SoundEffectID and AmbientSoundID, an AmbientSoundComposition type and the AmbientSoundChanged event. RuneLite's own plugins now use the gameval sound IDs.
  • WorldType.HARDCORE_MAIN, IconID.HARDCORE_MAIN and ItemPrice.getWikiPriceHcm() are available. ItemManager no longer falls back to the Grand Exchange guide price when the wiki price looks manipulated; it returns the wiki price for the world type you are on.
  • The gameval classes (ItemID, NpcID, ObjectID, InterfaceID, VarbitID, DBTableID and others) are updated to the 2026-11-17 game data. The client and Hub development compile against them without changes.
  • This release contains only the RuneLite update. Fixes already merged to development ship in the next release, and the launcher is unchanged.

How to update

Restart Microbot through the launcher to get client 2.6.59. Your plugins and settings stay as they are.
